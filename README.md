# CodeAlpha_Calculator

A calculator built with HTML, CSS, and JavaScript, styled as a retro desk calculator with a green LCD-style display.

## Features
- All arithmetic operations: addition, subtraction, multiplication, division
- Real-time result display
- Clear (AC) and backspace
- Percent calculation
- Full keyboard support (numbers, operators, Enter, Backspace, Esc)
- Physical "key press" animation on every button

## Built with
- HTML
- CSS
- JavaScript
